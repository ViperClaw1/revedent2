# Revedent AI UI Kit

Initialize a new React project using Tailwind CSS and Lucide React icons. The brand is 'Revedent.ai', a premium, AI-driven dental billing company. Set the global font to 'Plus Jakarta Sans' (or a similar premium sans-serif like 'Inter'). The color palette must be: Pure White (#FFFFFF) for the background, Deep Navy Blue (#0B1120) for primary text and dark sections, Slate-500 (#64748B) for secondary text, and an electric Cyan (#06B6D4) for primary buttons, accents, and highlights.

Build a fixed, glassmorphism top navigation bar. Left side: The text logo 'revedent.ai' in Navy bold text with the '.ai' in Cyan. Center: Links for 'Services', 'Pricing', 'About', 'Resources'. Right side: A 'Book a Demo' button styled with a Cyan background, white text, slightly rounded corners (rounded-md), and a subtle hover effect (scale up 105% and add a cyan glow shadow). Make the nav responsive with a hamburger menu for mobile.
